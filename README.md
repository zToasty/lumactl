# lumactl 💡

Легковесная CLI-утилита и демон для управления контроллерами фоновой подсветки монитора (Adalight / Skydimo) в ОС Linux.

## Возможности
- 🔍 Автоматический поиск USB-порта контроллера.
- 🎨 Установка статичных цветов.
- 🎶 **Цветомузыка (Liquid Spectrum)** с прямым захватом аудио (Zero-Config PipeWire).
- 🚀 (В планах) Режим калибровки ленты и захват экрана (Wayland).

## Установка

Вы можете скачать готовый бинарник со страницы **Releases** (собирается автоматически через GitHub Actions).

Или собрать вручную (требуется Go 1.22+):
```bash
go build -o lumactl
```

### Первоначальная настройка
Контроллер подключается по USB (Serial port). Чтобы программа могла общаться с ним без прав суперпользователя (root), необходимо сгенерировать udev-правило:
```bash
sudo ./lumactl setup
```

## Использование (The Swiss Army Knife)

Программа работает по принципу "Единый бинарник — две роли". 
Вам нужно запустить демона (сервер), а затем отправлять ему команды.

### 1. Запуск демона
Демон захватывает порт и ждет команды:
```bash
./lumactl daemon
```
*(Рекомендуется настроить автозапуск демона через systemd).*

### 2. Управление подсветкой
Откройте другой терминал и используйте команды:

**Включить цветомузыку (Liquid Spectrum):**
```bash
./lumactl music
```
*(Программа сама найдет системный звук и начнет пульсировать в такт. Никаких виртуальных кабелей настраивать не нужно!)*

**Включить статичный цвет:**
```bash
./lumactl color red
./lumactl color #FF00FF
```

**Проверить статус:**
```bash
./lumactl status
```

**Выключить подсветку:**
```bash
./lumactl stop
```
