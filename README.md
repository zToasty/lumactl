# lumactl 💡

Легковесная CLI-утилита и демон для управления контроллерами фоновой подсветки монитора (Adalight / Skydimo) в ОС Linux.

## Возможности
- 🔍 Автоматический поиск USB-порта контроллера.
- 🎨 Установка статичных цветов.
- 🚀 (В разработке) Захват экрана и Ambient-подсветка (Wayland/PipeWire).

## Сборка и запуск

Проект написан на Go. Для сборки выполните:

`go build -o lumactl`

### Первоначальная настройка
Контроллер подключается по USB (Serial port). Чтобы программа могла общаться с ним без прав суперпользователя (root), необходимо сгенерировать udev-правила:

`sudo ./lumactl setup`

### Использование
Включение статичного цвета:

`./lumactl color red`
`./lumactl color #FF0000`
`./lumactl color off`
